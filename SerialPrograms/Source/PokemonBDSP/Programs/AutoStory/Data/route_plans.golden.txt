that test with PA_UPDATE_ROUTE_PLANS=1 to rewrite this file
(PA_ROUTE_PLANS_GOLDEN=<path> reads or writes another copy), and review
its diff.
turns: direction changes between legs. open: legs that stop in the open
(tapped, not held to a wall). localization: the wall holds at the start
that only bring several start tiles to one (plan_recovered_route()'s
anchor); 0 from one start tile.
