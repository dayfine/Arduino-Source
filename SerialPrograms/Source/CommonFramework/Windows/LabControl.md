# Lab Control (replaced)

The `LabControl/` folder is gone. Its job, starting and stopping the selected
program from a script, is done by the lab channel: the folder `Lab/` in the
same place, where `start` and `stop` are lines in a request file and `state`
has five lines. See [Lab.md](Lab.md) for the files, every command and a
worked example. This file stays one release so old links land somewhere.
